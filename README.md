# Лічильник React з `useMemo` та `useCallback`

Демо: [hillel-use-memo-s7el-red.vercel.app](https://hillel-use-memo-s7el-red.vercel.app/)

Невеликий застосунок на React і TypeScript: лічильник збільшує значення після натискання кнопки та показує результат обчислення `count ** 5 + count`. Інтерфейс оформлено як картку, вирівняну по центру сторінки.

## Що демонструє проєкт

- `useState` зберігає поточне значення лічильника.
- `useMemo` запам'ятовує результат обчислення і перераховує його, коли змінюється `count`.
- `useCallback` зберігає посилання на функцію збільшення. Функціональне оновлення стану (`setCount((currentCount) => currentCount + 1)`) дає змогу залишити масив залежностей порожнім і водночас використовувати актуальне значення лічильника.
- Стилі компонента зібрані у `src/App.css`.

## Запуск локально

Потрібен Node.js та npm.

```bash
npm install
npm run dev
```

Vite виведе адресу локального сервера у терміналі.

## Перевірка та збірка

```bash
npm run lint
npm run build
```

Для локального перегляду production-збірки:

```bash
npm run preview
```
